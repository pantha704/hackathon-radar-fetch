## Output files (`data/`)

| File | Meaning |
| --- | --- |
| `hackathons.md` | Live catalog: every `open` / `upcoming` event, sorted online-first. |
| `online.md` | Online lens: live events you can join from anywhere (mode `online`). |
| `archive.md` | Closed history: events that ended, kept forever, newest first. |
| `radar.json` | Canonical store: run metadata + every event as structured data. |

Every markdown file carries a `**Last updated:** <date> <time> IST` header with the run's `open` / `online` / `new` counts. Missing values render as `—`, never guessed.

## Setup

```bash
uv sync                        # or: python -m venv .venv && .venv/bin/pip install -e .
scripts/provision_browsers.sh  # link the stealth browser into .pw-browsers/
```

## Running

```bash
PLAYWRIGHT_BROWSERS_PATH=$PWD/.pw-browsers .venv/bin/python -m radar.cli run
```

One run: fetch all enabled sources → normalize + dedupe → write `data/` → regenerate this README's online list → commit `data: radar run <ISO>` (only when something changed) → push. Real runs take about a minute (eleven live fetches).

Flags:

| Flag | Effect |
| --- | --- |
| `--sources a,b` | Run only these source ids (default: all enabled). |
| `--dry-run` | Skip git entirely (output files are still written). |
| `--no-push` | Commit but do not push. |
| `--limit N` | Cap events taken per source. |
| `--data-dir PATH` | Custom output directory (requires `--dry-run`; a custom dir leaves the README alone). |

## Freshness — no silent staleness

- Refreshes happen **on command only**. Nothing changes until someone runs `radar run`; the `Last updated` header always tells you exactly how old the data is.
- A source that fails to fetch or parse is listed under `failed:` in the run summary and its previous rows are retained **unchanged** (`last_seen` frozen) — never hidden, never dropped, never fabricated. Other sources refresh normally in the same run.
- Markup-drift guard: a source that suddenly parses zero rows while the previous run still had non-closed rows is treated as a **failure**, not as "no hackathons today".
- Rows are removed only when their source was successfully processed and genuinely no longer lists them; closed events move to `archive.md` and stay forever.
- Known deviation: retry/backoff/pacing hardening is deferred; a failed source is re-runnable with a single command (`radar run --sources X`) — failures are always surfaced, never hidden.

## Sources (11)

- **API:** devpost (JSON listing endpoint).
- **Browser** (rendered via the stealth browser): devfolio, mlh, dorahacks, superteam, lablab, ethglobal, taikai, hackathon.com, wemakedevs, hackclub.

**Walled — known coverage gap:** `unstop.com` and `hackerearth.com` are **not** covered. Both returned HTTP 403 to every fetch route tried, including the stealth browser (an IP-level wall against this host, not a markup problem), so the catalog contains no unstop/hackerearth rows. That absence is documented, never papered over — see [`docs/adr/0001-walled-sources.md`](docs/adr/0001-walled-sources.md) for the evidence and revisit triggers. Re-probing is cheap: `.venv/bin/python scripts/probe_fetch.py <url>`.

## Cadence

On command **only** by default — there is no automatic refresh. `deploy/cron.example` ships a **disabled** crontab template (suggested: daily 09:00 IST) that can be enabled deliberately if you ever want it; until then the data refreshes exactly when you run it.

## Development

- venv: `.venv` (uv, Python 3.11).
- tests: `.venv/bin/pytest -q` — network-free (recorded fixtures in `tests/fixtures/`).
- Browser fetches need the stealth browser wired up: `scripts/provision_browsers.sh` rebuilds the `.pw-browsers/` symlink tree, then run with `PLAYWRIGHT_BROWSERS_PATH=$PWD/.pw-browsers`.
- Vocabulary: `GLOSSARY.md` · walled-sources ADR: `docs/adr/0001-walled-sources.md`.

Stack: CloakBrowser stealth for every browser fetch · crawl4ai fetch/extract framework · markdown + JSON data in this repo.
